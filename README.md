#  Kids Tech Learning

A safe, offline, single-file educational web app that teaches underprivileged children (ages 5–10) the basics of alphabet, numbers, technology, and safe tech habits — with **no ads, no tracking, and no internet required**.
Built with pure HTML, CSS, and Vanilla JavaScript. No frameworks. No dependencies. Just one `index.html` file.
##  What's Inside

### 🔤 ABC — 26 Letters
- A to Z, each with a word and emoji (Apple 🍎, Ball ⚽, Cat 🐱...)
- Tap any card → hears "A for Apple"
- 26 cards in a responsive grid

### 🔢 Numbers — 1 to 10
- Visual number cards with emojis (1️⃣ 2️⃣ 3️⃣...)
- Tap → hears the number

### 💻 Tech Words — 10 Terms
Beginner-friendly definitions of:
- 💻 Computer
- 🌐 Internet
- 🤖 AI (Artificial Intelligence)
- 🦾 Robot
- 📱 Phone
- 📟 Tablet
- ⌨️ Keyboard
- 🖱️ Mouse
- 🖥️ Screen
- 👨‍💻 Code

Tap any card → hears the term and its description.

### ❤️ Good Habits — 10 Lessons
Safe tech habits for kids:
1. 📚 Use tech for learning
2. 🔒 Keep personal info secret
3. ⏰ Take breaks
4. 🤝 Be kind online
5. 👨‍👩‍👧 Ask parents first
6. 🧠 Think before you believe
7. 🔑 Keep passwords safe
8. 📵 Limit screen time
9. ❤️ Use tech to help others
10. 🌟 Learn something new daily

## 🔊 Speech Support

Every card, tech word, and habit is **tappable** and uses the browser's built-in **Web Speech API** to read it aloud.

- No external API
- No internet needed
- Voice settings: rate 0.9, pitch 1.1, lang en-US
- Works on Chrome, Edge, Safari, Firefox

## 🔒 Safety & Privacy

- ✅ No ads

## 🎨 Design Choices (Why It Looks Like This)

| Choice | Reason |
|---|---|
| Comic Sans MS font | Kid-friendly, readable |
| Soft gradient background | Calm, not distracting |
| Rounded cards | Soft, safe feel |
| Emojis everywhere | Visual learning for non-readers |
| Big buttons | Easy for small fingers |
| Speech on tap | Helps kids who can't read yet |


## 🎯 Purpose

Built for children in underprivileged areas who:
- Have weak educational basics
- Cannot afford paid learning apps
- Are exposed to unsafe content online
- Have limited or no internet access

The app focuses on **accessibility, safety, simplicity, and engagement** — starting from ABC and counting, then introducing technology and safe tech habits.
